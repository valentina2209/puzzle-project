# 🧩 Розв'язувач головоломки

Розв'язання даної головоломки здійснювалося за допомогою TypeScript. Для розв'язання задачі збору цифрових ланцюжків за допомогою теорії графів (алгоритм Ейлерова шляху) в середовищі Node.js. Проєкт створено для демонстрації навичок алгоритмічного мислення, чистої архітектури коду та сучасних стандартів TypeScript.

---

## 🚀 Про проєкт

Ця програма зчитує набір перекривних цифрових фрагментів із текстового файлу, будує орієнтований граф та відновлює єдиний безперервний найдовший рядок (**Ейлерів шлях**), правильно з'єднуючи краї фрагментів.

Ключові особливості:

- **Графовий підхід:** Реалізація списків суміжності, підрахунок вхідних (in-degree) та вихідних (out-degree) степенів вершин.
- **Ітеративний DFS обхід:** Використання явного стека замість рекурсії для уникнення переповнення стека на великих графах.
- **Сувора типізація:** Повністю написано на TypeScript із налаштуваннями `strict`.
- **Безпечна робота з файлами:** Надійна обробка помилок читання файлової системи.

## 📁 Структура проєкту

```text
├── src/
│   └── puzzleSolver.ts    # Основний алгоритм, парсер файлу та точка входу
├── .gitignore             # Правила ігнорування для Git (node_modules, dist тощо)
├── package.json           # Метадані проєкту та залежності
├── tsconfig.json          # Конфігурація компілятора TypeScript
└── fragments.txt          # Вхідний файл із цифровими фрагментами
```

## ⚙️ Встановлення та налаштування

1. **Клонуй репозиторій:**

   ```bash
   git clone https://github.com/valentina2209/puzzle-project
   cd puzzle-project
   ```

2. **Встанови залежності:**

   ```bash
   npm install
   ```

3. **Встанови типи для Node.js:**
   ```bash
   npm install -D @types/node
   ```

---

## 🚀 Запуск проєкту

Ти можеш запустити скрипт напряму за допомогою `ts-node`:

```bash
npx ts-node src/puzzleSolver.ts
```

Або скомпілювати та запустити JavaScript-версію:

```bash
# Зібрати проєкт (скомпілює TS у JS у папку /dist)
npm run build

# Запустити скомпільований файл
node dist/puzzleSolver.js
```

---

## 📝 Формат вхідних даних (`fragments.txt`)

Вхідний файл має містити один цифровий фрагмент на рядок. Кожен фрагмент розглядається як спрямоване ребро, де перші 2 цифри — це початкова вершина, а останні 2 цифри — кінцева. Приклад:

```text
1234
3456
5678
```
